Champion entry for make.fun competition: "Sum up 22 November's world news in one image".

## Overview

This repository contains the automated bot entry for the make.fun news image challenge. The bot publishes a synthesized visual digest capturing key geopolitical and global developments for November 22, 2026.

## Execution

The submission runs inside the make.fun containerized execution harness:
```bash
python3 -P -s /bot/main.py
```

The script copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` and completes with exit status 0.
